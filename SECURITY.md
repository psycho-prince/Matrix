# Security Policy

## Supported Versions

Currently, the Generational Artificial Life (GAL) framework is a research prototype.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to the repository maintainers rather than creating a public issue. We will review the report and respond accordingly.
