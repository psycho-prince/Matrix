# Contributing to Generational Artificial Life

Thank you for your interest in contributing to the Generational Artificial Life (GAL) framework!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/generational-artificial-life.git`
3. Create a branch for your feature or bug fix: `git checkout -b feature/your-feature-name`

## Submitting Pull Requests

1. Ensure all tests pass.
2. Update documentation if necessary.
3. Submit a pull request describing the changes and their motivation.
