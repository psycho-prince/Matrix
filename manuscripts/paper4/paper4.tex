\begin{abstract}
This manuscript specifies a reproducible evaluation of a generational parameter-inheritance method for class-incremental continual learning. Earlier repository experiments used synthetic digit-like templates and reported results that did not establish superiority over established continual-learning baselines. Those results are not presented here as canonical MNIST evidence. We introduce a canonical MNIST Split-MNIST protocol and a paired-seed comparison against Elastic Weight Consolidation (EWC), Synaptic Intelligence (SI), Gradient Episodic Memory (GEM), Experience Replay (ER), and Dark Experience Replay++ (DER++). The initial benchmark is designed for 20 paired seeds, with final sample size determined by prospective power analysis and a pre-specified minimum meaningful effect. Numerical results will be inserted only from the archived per-seed outputs generated by the reproducibility workflow.
\end{abstract}

\section{Scope and claim discipline}
Catastrophic forgetting is the loss of performance on previously learned tasks after sequential learning. This study asks whether a generational parameter-transmission rule can provide a useful stability--plasticity trade-off under explicit resource constraints. The hypothesis is empirical and is not assumed to be true. The prior synthetic 8-by-8 digit-prototype experiment is retained only as exploratory development evidence and is not described as MNIST.

\section{Canonical dataset and task protocol}
The benchmark uses the canonical MNIST training and test sets distributed by \texttt{torchvision.datasets.MNIST}. Images are converted to float tensors and flattened by the model. Five class-incremental tasks are presented in a fixed order: $(0,1)$, $(2,3)$, $(4,5)$, $(6,7)$, and $(8,9)$. Each task uses a seeded, class-balanced subset. Evaluation is performed on each task's held-out test subset after every task; final average accuracy is the mean over all five task test subsets.

\section{Methods}
All methods use the same MLP architecture, task order, per-task sample cap, minibatch size, number of epochs, optimizer family, and initial seed. The comparison includes:
\begin{itemize}
\item GAL: a generational child model formed by combining parent parameters with independent initialization-scale noise, followed by the same model capacity constraint.
\item EWC: quadratic parameter consolidation weighted by a diagonal Fisher estimate.
\item SI: path-integral importance estimates that penalize movement in parameters important to prior tasks.
\item GEM-style projection: current gradients are adjusted to satisfy non-negative inner products with stored task reference gradients. The implementation is a transparent iterative half-space projection approximation and must not be represented as the full quadratic-program GEM algorithm without further validation.
\item ER: a bounded episodic exemplar buffer used in the fixed minibatch budget.
\item DER++: exemplar replay with stored previous logits and a distillation penalty.
\end{itemize}

The auxiliary-memory ceiling is 1 MiB per method. Model parameters are reported separately from auxiliary state. Optimizer updates and current-task minibatch sizes are fixed; method-specific additional operations (Fisher estimation, reference-gradient projection, replay/distillation) must be separately accounted for. Wall-clock time alone is not treated as a hardware-independent compute metric. The first run is therefore a controlled update-budget and memory-ceiling comparison, not yet a proof of equal FLOPs. A strict equal-FLOP follow-up is required before any claim of compute efficiency.

\section{Primary outcomes and statistics}
The primary outcome is final average accuracy across the five task test subsets. Secondary outcomes include average forgetting, per-task accuracy trajectories, wall-clock time, optimizer updates, and peak auxiliary-memory use. Seeds are paired across methods. Pairwise GAL-versus-baseline tests use paired $t$-tests, with Holm correction across the five comparisons; effect sizes use paired Cohen's $d_z$. Confidence intervals and per-seed data are archived. The 20-seed run is a pilot. A final sample size is chosen using prospective power analysis and a pre-registered minimum meaningful difference, not repeated significance testing.

\section{Inheritance rule: what is proved}
For a fixed parent tensor $W$, independent zero-mean noise $\Xi$, and $f\in[0,1]$, define
\[
W'=fW+\sqrt{1-f^2}\,\Xi.
\]
Then
\[
\mathbb{E}[\|W'\|_F^2\mid W]
=f^2\|W\|_F^2+(1-f^2)\mathbb{E}[\|\Xi\|_F^2].
\]
This follows by expanding the squared Frobenius norm and observing that the cross term has zero expectation. Expected squared norm is preserved only when $\mathbb{E}[\|\Xi\|_F^2]=\|W\|_F^2$ (apart from endpoint cases). The current implementation uses fan-in-scaled noise, scales biases by $f$ without replacement noise, and applies a global capacity projection. Consequently, it does not establish pathwise conservation or general conservation of total parameter energy. The method is described as variance-inspired stochastic inheritance, not energy-conserving inheritance.

\section{Results status}
The canonical Split-MNIST workflow downloads the official MNIST data, runs paired seeds, computes the baseline comparisons, and archives raw per-seed outcomes. Until that workflow completes successfully and its artifacts are independently inspected, no performance table or superiority claim is made in this manuscript. The historical 100-seed scalar-agent experiment is audited separately from the neural benchmark.

\section{Reproducibility}
The exact code revision, dependency versions, task sampling seeds, raw per-seed JSON, statistical analysis, and workflow logs are required for a reproducible release. A passing software CI run is not itself evidence of scientific validity or peer review.
